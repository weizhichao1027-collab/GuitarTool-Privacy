隐私状态 · 音频留在本机

你的练习声音，只留在你的设备上

吉他工具（GuitarTool）1.1.4 隐私政策 · 更新日期：2026 年 10 月 20 日 · 新增分析条款自 1.1.4 首次向用户提供之日起适用

无需账户音频不上传分析由你选择

卫智超（以下简称“开发者”）重视你的隐私。本政策适用于 GuitarTool 的 iPhone、iPad、Apple Watch 应用及配套网站，说明调音、节拍练习、人声数拍、和弦查询和主屏幕小组件如何处理信息。App Store 列示销售者为 Shanghai Qishan Cultural Communication Co., Ltd.。Android 与 Wear OS 的处理方式见独立 Android 隐私政策。

收集范围与你的选择

GuitarTool 不出售个人信息，不用于广告或跨应用、跨网站追踪。应用无需注册或登录。我们不通过使用分析收集姓名、邮箱、电话号码、精确位置、通讯录、照片、广告标识符、录音或精确音高数据。你主动联系支持时提供的信息另见“联系开发者”。

iPhone 与 iPad 提供可选的“帮助改进 GuitarTool”使用分析，默认关闭；只有在你阅读说明并主动同意，且该版本已配置统计项目后，才初始化 PostHog 官方 SDK 和发送事件。拒绝不会影响调音、节拍器、和弦库、主题或购买。Apple Watch 和主屏幕小组件本期不独立初始化该 SDK、不独立发送分析事件。

版本范围：本页公开说明 1.1.4 的信息处理方式；可选分析条款自该版本首次向用户提供之日起适用，且只有你主动同意后才开始采集。已发布的 1.1.3 不包含第三方分析 SDK，也不向开发者上报功能使用分析；更新本政策不会使 1.1.3 开始采集。

麦克风与音频处理

iPhone、iPad 与 Apple Watch 上的调音器只有在你主动开始调音时才会请求并使用相应设备的麦克风权限。麦克风音频用于在当前设备上实时计算音高、音分、信号强度和稳定度。手表调音器支持吉他、尤克里里、贝斯和半音阶模式；打开调音页面本身不会开始收音。

  • 音频完全在设备本地处理，不会发送到开发者或任何第三方服务器。
  • 麦克风录音不会保存到文件、相册、iCloud 或其他持久存储。
  • 停止调音、切换功能或应用进入后台后，实时采集会停止，音频处理缓冲会被释放；在 Apple Watch 上切换页面或离开 App 也会结束收音。
  • 你可以在 iOS/iPadOS 或 watchOS 系统设置中撤销 GuitarTool 的麦克风权限；撤销后对应设备的调音器无法使用。

人声数拍与试听

1.1.3 在 iPhone 与 iPad 的节拍器中新增“人声”音色。中文数字一到十二的预制 WAV 素材及不同速度版本包含在安装包内。正常数拍、选择音色时按当前 BPM 播放的“一、二、三、四”试听，以及速度阶段的素材选择与播放，均在设备上完成；不下载语音，不调用运行时 AI、语音合成或云端服务，不采集你的声音，也不请求麦克风或语音识别权限。界面语言不会把这组内置中文素材变成其他语言的报数。此功能不适用于 Apple Watch。

和弦卡片、照片与闪光灯

只有当你主动点击“保存到照片”时，应用才会请求照片“仅添加”权限，并把刚刚在设备上生成的和弦卡片写入系统照片图库。应用不会读取、浏览或上传你已有的照片和视频；拒绝权限不会影响调音、节拍器、和弦查询或系统分享。

启用节拍器闪光反馈时，应用只在前台且节拍器页面可见时控制设备闪光灯，不拍摄照片或视频，也不会读取相机画面。切换页面、进入后台或停止节拍器后，应用会请求立即关闭闪光灯。

本地设置与 App Group

为了记住你的练习环境，应用会在设备上保存节拍器速度、拍号、音色选择（包括“人声”）、训练方案（包括有声／静音小节、每段速度与小节数、循环设置）、自定义预设、调音预设、主题和界面语言等设置。音色可随自定义练习预设保存在本地；应用不会保存你的人声录音。部分节拍器状态通过 Apple App Group 在 GuitarTool 与其主屏幕小组件之间共享，以便小组件显示和控制同一套本地设置。

为避免在演奏中或过于频繁地请求评分，评分模块仅在本机保留有限的合格练习次数、练习日期、本地时区、用于去重的近期随机练习标识，以及已尝试提示的版本和时间。在该模块中，前台音频运行时长只用于判断一次练习是否满足条件，不保存完整练习时长日志。这些评分资格状态不与身份关联、不上传给开发者，不构成云端练习记录，也不记录你是否满意、给出的星级或评价内容。你同意可选分析后发送的汇总使用时长另见下节。Apple 决定是否显示系统评分界面；提交评价由 Apple 处理。

这些设置保存在你的设备上；界面语言可同步至配对的 Apple Watch。删除应用通常也会删除其本地数据；系统备份行为由你的 iOS 与 iCloud 设置决定。

网络、PostHog 与第三方服务

核心练习功能无需网络。你同意后，PostHog Cloud 代表开发者接收有限的功能事件，用于了解功能是否正常运行、练习工具使用情况、重复使用和主题购买流程，以改进产品。SDK 在你同意后还可能请求服务配置。它不用于广告；我们关闭自动页面/点击/生命周期采集、会话录制、远程功能标记、用户画像处理及基于 IP 的地理定位。

  • 设备 ID（随机安装标识）与事件时间：将同一安装中不同时间的使用关联起来，不与登录账号或其他设备合并。该标识不是真实姓名，但仍可关联使用记录，因此不能视为完全匿名数据。
  • 产品交互：工具或页面类别、开始/完成/失败、结束原因、汇总使用时长、乐器及调弦预设、节拍速度与训练模式、和弦查看/试听/分享，以及主题预览与应用。不会上传每拍或每帧数据、录音、精确音高、手动输入文本或分享内容。
  • 购买历史：主题/商品标识、购买发起及成功/取消/待批准/失败等结果、独立的恢复购买结果。不上传收据、交易号、购买令牌、银行卡信息或付款金额。
  • 性能数据：工具启动尝试和商品查询的汇总耗时，用于了解操作响应情况。
  • 其他诊断数据：音频启动/恢复、商品加载、购买等流程的有限固定错误码，用于分析功能运行问题；不上传崩溃日志或自由文本错误详情。

随事件发送的运行环境：平台、应用版本及构建号、系统版本、手机/平板类型、界面语言/语言区域设置和分析环境；工具过程和购买/恢复尝试使用随机标识关联同一次操作；SDK 传输还使用事件去重标识、会话及 SDK 版本等技术字段。

上述五类数据均用于产品分析，并通过随机安装标识关联同一安装的使用，不用于广告、个性化推荐或跨应用、跨网站追踪。

服务提供方：PostHog, Inc.；官网 posthog.com；隐私政策与联系方式。数据经加密网络连接发送到 PostHog Cloud 美国区项目并存储于美国。大陆用户的数据会传输至中国境外。关闭 GeoIP 只阻止基于 IP 的地理属性生成；PostHog 及网络基础设施仍会为接收请求、安全和服务运行处理来源 IP，不能理解为网络传输不涉及 IP。

事件可能先缓存在设备上，再批量发送或在网络恢复后重试。可在设置中随时关闭：此后停止采集，清除本机待发送事件和分析标识，再次同意会使用新随机标识。关闭开关不会自动删除云端已经收到的数据；正在传输的请求也可能已经送达。保存当前分析标识后，可通过下方邮箱申请查询或删除；若标识已清除且没有保留，我们可能无法将历史记录与你匹配。

保留与删除：分析事件自采集之日起最长保留一年，到期删除；你也可提前申请删除。在 App“帮助改进 GuitarTool”设置中查看并保存当前分析标识后，将该标识及删除请求发送至 weizhichao1027@gmail.com，开发者将据此查找并处理相关分析记录的删除。关闭分析不会自动删除已上传记录，请在关闭前保存标识。此期限针对分析事件；音频、本地设置、支持邮件及 Apple 交易记录分别按本政策对应章节处理。

主题素材与人声数拍素材内置。Apple StoreKit 处理购买和恢复，可能需要网络；开发者不接收银行卡信息，也不向自建主题服务发送交易凭据。可选分析只记录上述商品及结果，不代替 Apple 的交易记录。见 App Store 与隐私。

官网、技术支持和政策网页由 GitHub Pages 托管，托管方处理提供网页所需的网络请求信息，见 GitHub 隐私声明。本政策页不加载外部字体、分析脚本或追踪像素，不设置 Cookie。官网在线调音器仅在主动开始后请求麦克风，音高分析在浏览器本地进行，不保存或上传录音；停止、离开或隐藏页面时结束采集。在线节拍器在浏览器生成声音，无需麦克风。外部链接按对方政策处理信息。

儿童隐私

应用无需儿童提供账户或个人资料，使用分析默认关闭。我们不有意在缺少适用监护人同意的情况下收集儿童的分析数据；请监护人管理设备上的分析选择。如你认为儿童数据已被不适当地采集，请联系下方邮箱，以便核实并处理删除请求。

数据安全与你的选择

我们通过默认关闭、明确同意、有限事件字段、加密传输和限制分析访问权限来保护信息。音频不上传、不留存；本地评分资格、自定义练习预设名称及完整训练方案不作为分析事件上传。可选分析仅包含上文列出的节拍速度、训练模式等有限配置。你可以在应用设置中管理使用分析，在系统设置中管理麦克风与照片权限。删除应用通常清除本地数据，但不会删除已经上传的分析事件、你主动分享的卡片或 Apple 的交易记录。
